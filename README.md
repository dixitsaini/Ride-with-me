# Single Screen React Native App

This is a minimal single-screen React Native app scaffolded for beginners (Expo-managed).

Quick start:

1. Install dependencies:

```bash
npm install
# or
yarn
```

2. Start the dev server:

```bash
npx expo start
# or
npm run start
```

3. Open the app on a device or simulator using the Expo Dev Tools QR code or the platform shortcuts.

Files created:

- [App.js](App.js) — main single-screen UI
- [package.json](package.json) — project manifest and scripts
- [app.json](app.json) — basic Expo config
- [index.js](index.js) — app entry

If you prefer a bare React Native project instead of Expo, I can provide that setup too.
